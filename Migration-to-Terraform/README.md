## What is Terraform Import?

When you have **existing infrastructure in AWS** (created manually or outside Terraform), importing brings it under Terraform management **without destroying and recreating it**.


### Step 1 — Add import block in `main.tf`
```hcl
provider "aws" {
  region = "us-east-1"
}

import {
  id = "<instance-id>"   # existing AWS resource ID
  to = aws_instance.example    # what you want to call it in Terraform
}
```

> Get your instance ID from **AWS Console → EC2 → Instances**

---

### Step 2 — Generate config file
```bash
terraform plan --generate-config-out=generated_resource.tf
```

This automatically creates `generated_resource.tf` with ALL attributes filled in:
```hcl
# generated_resource.tf (auto-generated by Terraform)
resource "aws_instance" "example" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"
  subnet_id     = "subnet-abc123"
  key_name      = "my-key"
  tags = {
    Name = "my-instance"
  }
  # ... all other attributes auto filled
}
```

---

### Step 3 — Review generated file

- Open `generated_resource.tf`
- Remove any attributes that show errors or conflicts

---

### Step 4 — Copy resource block to `main.tf`
```hcl
provider "aws" {
  region = "us-east-1"
}

# keep import block here until after apply
import {
  id = "i-0699a528becfa1ade"
  to = aws_instance.example
}

# paste generated resource block here
resource "aws_instance" "example" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"
  subnet_id     = "subnet-abc123"
}
```

> ⚠️ Keep **BOTH** import block and resource block together at this stage

---

### Step 5 — Run terraform plan to verify
```bash
terraform plan
```

Expected output:
```
Plan: 1 to import, 0 to add, 0 to change, 0 to destroy
```

> ⚠️ If you see `1 to add` instead of `1 to import` — your import block is missing!

---

### Step 6 — Run terraform apply
```bash
terraform apply
```

Expected output:
```
aws_instance.example: Importing...
aws_instance.example: Import complete! ✅
Apply complete! Resources: 1 imported, 0 added, 0 changed, 0 destroyed.
```

---

### Step 7 — Remove import block after success
```hcl
provider "aws" {
  region = "us-east-1"
}

# only keep resource block after successful apply
resource "aws_instance" "example" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"
  subnet_id     = "subnet-abc123"
}
```



## Importing Multiple Resources at Once
```hcl
import {
  id = "i-0699a528becfa1ade"
  to = aws_instance.example
}

import {
  id = "sg-abc123"
  to = aws_security_group.example
}

import {
  id = "subnet-abc123"
  to = aws_subnet.example
}

# generate all configs at once
terraform plan --generate-config-out=generated.tf
```
